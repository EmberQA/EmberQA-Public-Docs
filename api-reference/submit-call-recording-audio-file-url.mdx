---
title: "Submit Call Recording (Audio File URL)"
description: "Submit a call for scoring using a publicly accessible audio file URL"
api: "POST /scoring/submitRecording"
---

## Request Body

<ParamField body="media_url" type="string" required>
  Publicly accessible URL to the audio file. Supported formats: `mp3`, `wav`.
</ParamField>

<ParamField body="agent_name" type="string">
  Name of the agent who handled the call.
</ParamField>

<ParamField body="language" type="string" default="en">
  Language code for the call audio.
</ParamField>

<ParamField body="is_inbound" type="boolean">
  Boolean flag indicating whether the call was inbound. Defaults to `true`
  when omitted.
</ParamField>

<ParamField body="transcript_url" type="string">
  Optional publicly accessible URL to a plain text transcript file.
</ParamField>

<ParamField body="transcript_text" type="string">
  Optional inline plain text transcript.
</ParamField>

<ParamField body="metadata" type="object">
  Optional key-value metadata to store with the call.
</ParamField>

<ParamField body="supporting_docs" type="string[]">
  Optional array of publicly accessible URLs to supporting documents.
</ParamField>

`transcript_url` and `transcript_text` are optional on this page. Use them only if you want to provide your own transcript alongside the audio URL.

## Response

<ResponseField name="message" type="string" required>
  Returns `File Accepted` when the call has been accepted for asynchronous
  processing.
</ResponseField>
