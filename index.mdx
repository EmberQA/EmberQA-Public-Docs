## What EmberQA Does

| Feature | Description |
|---------|-------------|
| **Call Scoring** | AI analysis of every call with consistent, objective scoring |
| **Document Scoring** | Score chat transcripts, emails, and written interactions |
| **Data Extraction** | Extract structured data from documents using templates |
| **Coaching Insights** | AI-generated guidance based on agent performance patterns |
| **Real-time Alerts** | Notifications for low scores and red flags |
