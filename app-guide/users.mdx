Manage who has access to your EmberQA organization.

## User List

The Users tab shows all users in your organization with:
- **Email** - User's email address
- **Role** - Their permission level
- **Status** - Active or pending invitation

## Inviting a New User

1. Click **Invite User**
2. Enter their email address
3. Select a role
4. Click **Send Invite**

The user will receive an email to set up their account.

## User Roles

| Role | Access |
|------|--------|
| **Admin** | Full access to all settings, data, and billing |
| **Manager** | Can view all data and manage agents, but not account settings |
| **Agent** | Can only view their own performance data and coaching insights |

## Managing Users

For each user you can:
- **Change Role** - Select a different role from the dropdown
- **Remove** - Click the delete icon to remove access
