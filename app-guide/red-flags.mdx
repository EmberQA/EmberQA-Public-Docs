Red Flags are automatic detections that alert you to specific issues in calls. When a red flag is triggered, the call is marked in the dashboard.

## Creating a Red Flag

1. Click **Create Red Flag**
2. Enter a **name** for the red flag (e.g., "Profanity Detected")
3. Enter a **description** - this tells the AI what to look for
4. Save

The description should clearly explain what condition triggers the flag. For example:
- "Agent used profanity or inappropriate language"
- "Agent failed to verify customer identity"
- "Agent promised something not within policy"

## Managing Red Flags

The list shows all your configured red flags. For each one you can:
- **Edit** - Update the name or description
- **Delete** - Remove the red flag

## How Red Flags Appear

When a call triggers a red flag:
- It shows in the Dashboard with a red flag indicator
- The flag count appears in the call row
- Details are visible in the call detail view
- It appears in Daily Report red flag summaries
- **It can trigger real-time alerts** via email or webhook (configure this in the [Alerts](/app-guide/alerts) page)
