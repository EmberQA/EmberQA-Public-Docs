EmberQA uses AI to score your call recordings and documents against your criteria. Upload files, get scores, and identify coaching opportunities.

## App Structure

| Section | Purpose |
|---------|---------|
| **Operations** | Dashboard (view scores), Daily Reports, Workflows |
| **Performance** | Analytics, Coaching, Training |
| **Standards** | Rubrics (scoring criteria), Red Flags, Alerts |
| **Ingestion** | Upload files |
| **Settings** | Users, Agent Management, Metadata |

## Key Concepts

| Term | Meaning |
|------|---------|
| **Rubric** | Scoring criteria with categories and pass/fail items |
| **Red Flag** | Auto-detected issue (e.g., compliance violation) that triggers alerts |
| **Workflow** | Document processing to extract structured data |
| **Team** | Agent grouping for filtering and reporting |

## Quick Start

1. Set up your [Rubrics](/app-guide/rubrics) (what you want to score)
2. [Upload](/app-guide/upload) recordings or documents
3. View results in the [Dashboard](/app-guide/dashboard)
