Use **Agent Aliases** to standardize name variations so reporting stays accurate.

This is helpful when transcripts contain abbreviations, misspellings, or alternate spellings for the same person.

## Find the Person to Fix

Open **Account Settings > Agent Aliases** and search for the user whose transcript names need cleanup.

Users are grouped by login-access users, agent-only users, and inferred or unassigned names. Start with inferred or unassigned names when reporting shows activity for someone who has not been fully configured yet.

## Configure Aliases for a User

1. Search for the user
2. Click **Configure**
3. Review **Current Aliases**
4. In **Add Alias**, enter an alternate name that appears in transcripts
5. Save to add the alias

## Remove an Alias

1. Open **Configure** for the user
2. In **Current Aliases**, remove the alias you no longer want
3. Confirm removal

## Example Alias Patterns

Common aliases include abbreviated names, system IDs, misspellings, or alternate spellings. For example, `John D`, `JDoe`, and `Jon Doe` might all map to `John Doe`.

## When to Use This vs User Management

- Use **User Management** to create users, control login access, and assign teams
- Use **Agent Aliases** to normalize alternate names for scoring and analytics
