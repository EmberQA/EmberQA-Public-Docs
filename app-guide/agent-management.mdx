Map agent names from your call recordings to standardize reporting. This is useful when:
- The name in transcripts doesn't match the agent's actual name
- Multiple spellings should be consolidated to one agent
- You want to standarize name spellings

## Agent Name Mappings

### Adding a Mapping

1. Click **Add Mapping**
2. Enter the **Source Name** - the name as it appears in transcripts
3. Enter the **Target Name** - the correct/standardized name
4. Click **Save**

All calls with the source name will now report under the target name.

### Example Use Cases

| Source Name | Target Name | Why |
|-------------|-------------|-----|
| "John D" | "John Doe" | Standardize abbreviated names |
| "JDoe" | "John Doe" | Merge system IDs with real names |
| "Jon Doe" | "John Doe" | Standardize name spellings |

## Teams

Tea let you group agents into teams for filtering and reporting.

### Creating a Team

1. Click **Add Team**
2. Enter a team name (e.g., "Sales Team", "Support")
3. Assign agents to the team

### Using Teams

Once configured, teams appear as filters in:
- Dashboard
- Analytics
- Coaching Opportunities

This lets you view performance by team rather than individual agents.
